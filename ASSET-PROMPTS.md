# MerchantBoard image provenance

The hoodie, sneaker and tote are original generated product illustrations made with the built-in `image_gen.imagegen` tool on 2026-10-03. They represent fictional sample products, not a real merchant's stock.

Each shipping WebP has an adjacent `.webp.json` file containing the exact generation prompt. Native transparent PNG originals were resized and converted to WebP with alpha preserved. No design-comp crop ships as an asset.

The interactive sales visualization is real Three.js geometry calculated from order data. Its `brushed-metal.webp` texture was generated with the same built-in tool and is used as a bump and roughness map. Studio softboxes and floor reflections are rendered in Three.js. Its exact prompt is in `brushed-metal.webp.json`. The 2D trend is an accessible SVG chart generated from the same data.
